## ❤️ Favorites & Hidden Files

Favorites and hidden files are saved locally using `localStorage`.

* Hindi napupunta sa GitHub
* Hindi shared sa ibang visitors
* Hindi binabago ang actual files
* Browser mo lang ang may alam

At tandaan, **Hide ≠ Delete.**

So relax, hindi mo mabubura ang buong media collection mo dahil lang sa isang fucking button. **RUHE, SCHEISSE.**

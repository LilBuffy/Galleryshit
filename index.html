Add media

This gallery reads directly from the media/ folder — there's no upload button because there's no server to upload to. To add files:

  1. Copy your images, videos, GIFs, or audio files into the media/ folder.
  2. Run node scripts/generate-manifest.js to rebuild media/manifest.json.
  3. Refresh the page. If you're on GitHub Pages, just commit and push — the included workflow regenerates the manifest and redeploys automatically.

Supported: JPG, PNG, WebP, AVIF, BMP, SVG, GIF, MP4, WebM, MOV, OGG, MP3, WAV, M4A, FLAC.
